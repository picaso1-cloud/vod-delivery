Updates now work without the server.
- The app still asks your server first (LAN, release notes, APK on the panel), but if that fails it checks the public GitHub releases directly — no token needed since the repo is public.
- The phone shows "Check for updates" and the installed version in the server settings screen.
- The TV app checks on launch (once per 6h) and shows the update dialog with the D-pad: OK downloads and installs, Back skips that version.
- The TV waiting screen shows its current version.
