Arabic search actually works now.
- Native titles are part of the name index and shown under the English title in results and details.
- Arabic normalisation: أ/إ/آ → ا, ة → ه, ى → ي, and the definite article "ال" is ignored when matching, so "القصة الكاملة" also matches "قصه كامله".
- Provider tags (V.SHAHID, V.FORJA) no longer overwrite the Arabic title during catalog parsing (256 series repaired).
- The name index was rebuilt (it was missing 2,763 titles) and plot matches can no longer outrank real title matches.
- Verified: "القصة الكاملة" returns all three anthology entries, and "جريمة في الزمالك" / "بني مزار" / "لعبة جهنم" each resolve.
