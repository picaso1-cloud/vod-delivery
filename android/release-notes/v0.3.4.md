In-app updates: the client now checks your server for a newer build and installs it without a cable.
- Update prompt on launch (max once per 6h) with the release notes and download progress.
- 'Later' skips that version until a newer one appears.
- Server endpoints: GET /api/app/update and /api/app/update/apk (token auth), served from the panel's android/dist folder.
- Setup: several LAN URLs can be entered comma-separated (home has two subnets: 192.168.1.x wired and 192.168.31.x Wi-Fi); the app tries each and then the public URL.
